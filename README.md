# 3d-room-walkthrough
A small interactive 3D room built in the browser. Pick wall and furniture colors, then walk through the room you designed using your keyboard and mouse.
#Features
choose a custom wall color
add chairs and tables in any color you pick
walk through the finished room with WASD controls and mouse look
#Built with
HTML
CSS
Java script
Three.js for 3D rendering
#how to run
download or clone this repository
open 3d-room-walkthrough.html in any modern web browser
pick your colors and furniture, then click Enter room
Clock once inside the room to start, then use WASD to move and your mouse to look around
Press Esc to release the mouse
#Background
this project was built as a way to connect a background in architecture with learning software development- translating spatial design thinking into interactive code.
